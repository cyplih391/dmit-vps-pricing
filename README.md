## 同样的价钱，Premium 和 Eyeball 差在哪

TINY、Pocket、STARTER、MINI、MICRO、MEDIUM 这六档，Premium 和 Eyeball 的标价完全一样，但 Eyeball 给的资源更多。TINY 是 1500GB 流量配 2Gbps，Premium 只有 1000GB 配 1Gbps；Pocket 的流量直接翻倍（3000GB 对 1500GB）；到 MEDIUM 是 30000GB 对 15000GB，带宽同为 10Gbps。

同一台机器、同样的价格，Premium 少给的那部分流量和带宽，就是线路的价钱。DMIT 在国内圈子里被叫作 CN2 GIA 头部玩家，说的是 Premium 这条线，你付的溢价买的是回程路由。如果用途本身不依赖回程质量，比如跑计算、做面向海外的站点、当备份节点，Eyeball 同价给双倍资源，没有理由选 Premium。

Tier 1 是价格最低的一条，WEE 36.9 美元/年，1 核、20G SSD、1TB 流量三个机房同价。这个价位和 RackNerd 那类年付机落在同一个区间，适合对国内访问没有要求的用途。

## 便宜的那部分钱省在哪

低价档的便宜不是白来的，条款里都写着。

**超流量直接限速到 1Mbps。** ByteVirt 大部分套餐超出月流量后，端口被限到 1Mbps，这个速度打开网页都费劲，等于断网。买之前按实际用量算，别按“能超”来规划。

**特价套餐明确不退款。** ZgoCloud 的 Specials 系列页面上写着 no refunds，年付 36.8 美元的便宜里，有一部分是放弃退款权换来的。

**100Mbps 后面还跟着“公平使用”。** ZgoCloud 香港带宽按公平使用原则提供，长期跑满有被限速的可能，跑下载或中转的要留意。

**客服和超售是低价档的常见代价。** ByteVirt 的公开评价两极化，批评集中在工单要等几个小时甚至一天、偶尔超售导致晚高峰性能打折。这不影响跑脚本，影响的是出问题时你多快能恢复。

DMIT 自己的条款也有边界，而且写得很具体：3 天全额退款要求流量不超过 30GB；“网络不好”被明确列为不予退款的情形；同一系列累计退款满 3 次不再受理；IP 在部分地区不可用但流量已超 3GB 也不退。换句话说，买之前线路要先确认好，别指望用退款来试错。

## 真实总成本：第一年和第二年

DMIT 目前所有在售套餐的续费价与首次购买价一致，第二年不会突然跳价。这一点在 VPS 圈不算普遍，很多低价方案的成本都藏在第二年。

按两个典型配置算：

- TINY（洛杉矶 Premium）：10.9 美元/月，第一年 130.8 美元，第二年还是 130.8 美元，两年合计 261.6 美元。
- WEE（Tier 1）：36.9 美元/年，两年 73.8 美元，比很多低价年付机的两年总价还低。

对照组是 RackNerd，同样是续费同价，35.99 美元/年的 2GB 套餐两年 71.98 美元。这类方案的成本曲线是平的，做预算时不用给第二年留涨价空间。反过来，任何“首年很便宜”的年付方案，下单前都该先确认续费价，这是低价档最容易踩的坑。

## 谁该买，谁别买

- **一年预算 40 美元以内，用途是学 Linux、跑脚本、做备份**：WEE 能用，但它不是 Premium 线，国内访问别期待；同价位有内存更大的年付机，看你更在意线路还是配置。
- **网站或 API 面向国内用户，每月能出 10–20 美元**：洛杉矶 Premium 的 TINY 起步，流量吃紧就上 Pocket。这是 DMIT 整个产品线里性价比最集中的一段。
- **需要香港，但一个月预算不到 20 美元**：DMIT 没有对应产品，别硬上，换机房或换商家。
- **要跑下载、视频中转这类吃带宽的业务**：从 STARTER 起（34.9 美元/月，3000GB 流量、10Gbps），但同价位低价商家给的价格更低，先算清流量再决定。
- **很在意退款保障**：3 天全额加 30 天部分退款，比“特价不退款”友好，但“网络不好”不在退款范围内。

## 常见问题

**能退款吗？**
购买 3 天内且流量不超过 30GB，可以全额退；30 天内按剩余价值部分退，扣支付网关手续费。退到账户余额不收手续费，支付宝退款也不收。

**支持支付宝吗？**
支持。信用卡、PayPal、支付宝三种都能付款，国内用户没有门槛。

**续费会涨价吗？**
目前续费价与首次购买价相同，第二年的支出可以按首年金额预估。

**香港和洛杉矶怎么选？**
看预算和用户位置。洛杉矶 TINY 10.9 美元/月，香港 TINY 39.9 美元/月，同名不同价，差价来自机房和线路。用户集中在华南、对延迟极敏感，香港的低延迟有价值；只是建站给国内看，洛杉矶 Premium 的回程够用，价格只有香港的四分之一左右。

**月付还是年付？**
表里 WEE 按年付出售，其余按月付标价。周期和实付金额在结账页可选可查，先把周期确认好再付款。

## 最后怎么定

一年预算不到 50 美元，选 WEE 36.9 美元/年，或者同价位内存更大的年付机，取决于你更缺线路还是更缺内存。每月能出 10–20 美元、国内访问不能将就，洛杉矶 Premium 从 TINY 起步，需要更多流量就上 Pocket。一定要香港，先确认预算撑不撑得住 39.9 美元/月，撑不住就换机房，这是三个选择里最容易后悔的一个。

下单前确认两件事：结账页显示的计费周期和实付金额（WEE 是年付，其余是月付），以及退款窗口的边界（3 天内、30GB 以内才是全额）。
